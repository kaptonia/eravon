# ERAVON family components

Shared components of the three desktop apps of the family (ZIKARON, GALEED, ERAVON). Each component carries a family version number. A project that changes a component bumps its number at release; the others see the higher number, read the diff between the two releases of that project, and decide what to pull. The number records what was done, not bytes; it moves only at release.

This list is ERAVON's, as of release 0.1.0. Paths are relative to this repository at that release. The machine-readable form is `family-components.json`; the literals a port must replace are in `crates/eravon-literals/family-literals.json`. It follows ZIKARON 0.1.5 (`7d44f974`, tag `v0.1.5`): its 24 rows take ZIKARON's version and code (`one-file` for its reading half: this product reads a record package whether it is one file or a folder, and writes none), and `md-editor` is proposed for the family from GALEED. A component whose origin is ZIKARON follows its code: each home file is ZIKARON's file renamed by `tools/family/family-rename.json`, and every difference from it is a rename, a literal or wiring. The command line's contract is `CLI-SCHEMA.md`.

Where, Tests and In no component are read from the source: a home is closed over what its files declare and reach (module declarations, same-crate paths, crate roots and manifests), and every test in the components' files and test files is a component's or listed with why.
